# 🌌 Fancy Gradient Project Cards UI

A modern and elegant **dark + blue themed UI** featuring animated project cards with modal pop-up descriptions.  
Built using **HTML, CSS, and JavaScript** — no frameworks, fully responsive, and lightweight.

## ✨ Features

### 🎨 Dark + Blue Premium Theme
Aesthetic deep-blue layout with neon gradients, soft glows, and modern UI styling.

### 🃏 Interactive Project Cards
- Gradient borders  
- Smooth hover animations  
- Thumbnail images  
- Clean layout with tags and progress bars  

### 💬 Modal Pop-Up Descriptions
Click any project card → a modal pops up showing:
- Project Title  
- Clean 4-line description  
- Close button  

### 🧭 Sidebar Navigation
Includes:
- Dashboard  
- Projects  
- Teams  
- Settings  
- New Project button  

### 📱 Fully Responsive
Works across:
- Desktop  
- Tablets  
- Mobile (auto-grid layout)
